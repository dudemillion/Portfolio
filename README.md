# Nikhil Bhalla — Portfolio

My personal portfolio highlighting selected projects in machine learning,
web development, and algorithms.

## Featured projects

- **AI-Powered Misinformation Detector** — a Python and Streamlit application
  using TF-IDF and logistic regression, with word-level explanations and a
  documented comparison with DistilBERT.
- **BFS Pathfinding Visualizer** — an interactive JavaScript grid that finds
  and displays a shortest path around user-defined walls.

## Built with

- Astro
- Tailwind CSS
- TypeScript
- GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
